- 摘要：UNLABELLED: Meta2Data is a modular, largely automated pipeline implemented in Python and Bash for the retrieval, standardization, and processing of public microbiome sequencing data. It retrieves metadata from major public repositories, including INSDC and CNCB, using user-provided keywords or BioProject/BioSample identifiers. Retrieved metadata are standardized using a synonym dictionary and then subjected to manual curation. Based on the curated metadata, Meta2Data downloads the corresponding raw sequencing data and processes them using standardized workflows based on DADA2 or VSEARCH. The pipeline supports both single- and multiple-target-region datasets and produces integrated feature tables, taxonomic assignments, and phylogenetic trees for downstream microbial community analyses.
