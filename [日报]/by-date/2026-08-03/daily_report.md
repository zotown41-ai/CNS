### Bioinformatics

#### NextLongIso：一种用于多维长读长RNA测序分析的综合性Nextflow流程工具
- 日期：2026-08-03
- 作者：未提供
- 文章类型：期刊文章
- 研究问题：长读长RNA测序技术，如Pacific Biosciences公司的PacBio技术和Oxford Nanopore Technologies公司的ONT技术，能够直接分析全长转录本及其转录组结构特征。
- 核心发现：
  1. 然而，对于长读长RNA测序数据的分析目前仍依赖于多种不同的工具，这些工具之间的方法差异导致人们无法获得关于长读长转录组中转录本结构、表达水平及其调控机制的统一认识。
  1. 我们提出了NextLongIso这一可扩展且可复现的Nextflow分析流程，该流程能够实现对多层面转录调控机制的协同分析。
  1. NextLongIso并非仅仅专注于转录本的重建，而是将转录本鉴定与下游的调控分析相结合，从而能够全面解析来自PacBio和ONT数据集的可变剪接现象、异构体转换过程、转录本边界的动态变化（包括替代启动子及多聚腺苷酸化作用），以及与转座元件相关的转录活动。
- 摘要：包括 Pacific Biosciences (PacBio) 和 Oxford Nanopore Technologies (ONT) 在内的长读长 RNA 测序技术，能够直接分析全长转录本及其转录组结构。然而，针对这类数据的分析目前仍分散在多种工具中，这限制了人们从整体上理解长读长转录组的结构、表达模式及调控机制。我们开发的 NextLongIso 是一个可扩展且具有重复性的 Nextflow 工作流程，它能够协同分析转录组的多个调控层面。该工具并非仅专注于转录本的重建，而是将转录本鉴定与后续的调控分析相结合，从而能够同时解析 PacBio 与 ONT 数据集中的可变剪接现象、异构体转换机制、转录边界动态（包括选择性启动子及多聚腺苷化过程），以及与转座元件相关的转录活动。通过消除复杂的跨工具数据整合工作，这一统一分析框架有效促进了从转录本鉴定到对其功能变异进行深入解读的全过程。

可用性与实施方式： NextLongIso 是基于 Nextflow 开发的，可免费在 GitHub 和 Zenodo 上获取：
- GitHub 地址：https://github.com/YidanSunResearchLab/nf-LongIso.git
- Zenodo 存储地址：https://doi.org/10.5281/zenodo.21049837

补充信息： 相关补充数据可在线查阅 Bioinformatics 数据库。
- 链接：https://academic.oup.com/bioinformatics/advance-article/doi/10.1093/bioinformatics/btag518/8750111?rss=1
