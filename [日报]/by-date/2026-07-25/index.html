PCIPG2.0：用于蛋白质复合物识别的多组学融合和结构感知图自动编码

  • 日期：2026-07-25
  • 作者：未提供
  • 文章类型：未提供
  • 研究问题：蛋白质复合物执行细胞功能，但从蛋白质-蛋白质相互作用（PPI）网络中识别它们仍然具有挑战性，因为相互作用组不完整，并且纯粹拓扑驱动的聚类通常缺乏机械解释性。

核心发现：

  1. 在这里，我们提出 PCIPG 2.0，这是一个无监督框架，它明确解决了基于 PPI 的复杂发现中的两个主要瓶颈：交互缺失和机械特异性有限。
  2. PCIPG 2.0 首先融合多个组学视图，优先考虑高可信度候选蛋白质关联并增强观察到的相互作用组，然后通过聚合残基图上的残基嵌入来学习结构感知节点表示，并结合 PPI 级图自动编码器来推断潜在的复杂成员资格。
  3. 在五个酵母基准中，PCIPG 2.0 持续提高了代表性基线的复合物回收率，并产生了比大小匹配的随机集具有显着更高的基因本体语义一致性的预测复合物。

摘要：蛋白质复合物执行细胞功能，但从蛋白质-蛋白质相互作用（PPI）网络中识别它们仍然具有挑战性，因为相互作用组不完整，并且纯粹拓扑驱动的聚类通常缺乏机械解释性。在这里，我们提出 PCIPG 2.0，这是一个无监督框架，它明确解决了基于 PPI 的复杂发现中的两个主要瓶颈：交互缺失和机械特异性有限。 PCIPG 2.0 首先融合多个组学视图，优先考虑高可信度候选蛋白质关联并增强观察到的相互作用组，然后通过聚合残基图上的残基嵌入来学习结构感知节点表示，并结合 PPI 级图自动编码器来推断潜在的复杂成员资格。结果 在五个酵母基准中，PCIPG 2.0 持续提高了代表性基线的复合物回收率，并产生了比大小匹配的随机集具有显着更高的基因本体语义一致性的预测复合物。文献支持的案例研究和基于 AlphaFold3 的组装分析进一步表明，代表性预测与功能一致和结构​​合理的蛋白质组装一致。总之，这些结果表明，将多组学驱动的相互作用组完成与残基知情表示学习相结合，为不完整相互作用组测量下的蛋白质复合物识别提供了有用且机械知情的框架。可用性 源代码可在 GitHub https://github.com/hyx-1/PCIPG2.0 获取。 完整的重现性包，包括重现本手稿中报告的实验所需的代码、处理的数据、配置文件和材料，已存档在 Zenodo 上，存档 DOI https://doi.org/10.5281/zenodo.20133228 。 GitHub 存储库还提供基于 README 的使用说明

摘要：生物活性化合物的可扩展鉴定对于当代药物发现至关重要。这个过程面临着一个关键的权衡：结构筛选提供了可扩展性，但缺乏生物学背景，而高内涵表型分析提供了深入的生物学见解，但资源密集型。主要挑战是从噪声数据中提取鲁棒的生物信号，并将其编码为推理时不需要生物数据的表示形式。结果本研究提出了 DECODE（分解药物作用的细胞观察），这是一个框架，通过赋予化学表示与内在的生物语义以实现基于结构的计算机生物分析，从而弥补了这一差距。 DECODE 在训练期间利用有限的配对转录组和形态学数据作为监督信号，从而能够从化学结构中提取测量不变的生物指纹，并显式过滤模态特定的变异。在保留的检索、支架分割和 UMAP 聚类虚拟筛选基准中，DECODE 改进了功能检索和早期活性化合物优先排序。可用性和实现 DECODE 的代码和数据集可以在 https://github.com/lian-xiao/DECODE 获取

核心发现：

  1. 在存在插入缺失错误的情况下，利用条形码需要准确比对原始读数，以区分真正的插入缺失和插入缺失错误。
  2. 现有的策略通常依赖于为同源性比较而构建的对齐器，并且没有充分利用质量分数。

AstroLogics：用于分析布尔模型集合的基于模拟的框架

  • 日期：2026-07-25
  • 作者：未提供
  • 文章类型：未提供
  • 研究问题：布尔网络 (BN) 已成为建模细胞调节机制的通用工具，因为它们尽管简单，但仍能够捕获关键的生物学特征。

核心发现：

  1. 近几十年来出现了多种BN合成方法，旨在推断具有与实验数据相对应的动力学的BN。
  2. 通常，这些方法会生成多个 BN 候选者或“模型集合”。
  3. 虽然这些集合对于代表细胞群及其异质性很有价值，但它们通常被视为单个组件而不检查其组成特征。

摘要：布尔网络 (BN) 已成为建模细胞调节机制的通用工具，因为它们尽管简单，但仍能够捕获关键的生物学特征。近几十年来出现了多种BN合成方法，旨在推断具有与实验数据相对应的动力学的BN。通常，这些方法会生成多个 BN 候选者或“模型集合”。虽然这些集合对于代表细胞群及其异质性很有价值，但它们通常被视为单个组件而不检查其组成特征。结果我们提出了 AstroLogics，这是一种新颖的框架，旨在分析和识别 BN 模型集合中动态行为和逻辑调节的差异。该框架通过探索 BN 的状态转换图 (STG) 来计算 BN 之间的动态距离，从而能够对可能代表不同细胞命运或信号机制的相似功能模型进行聚类。 AstroLogics 还确定了管理每个集群的关键逻辑属性，突出了区分模型行为的核心监管结构。我们的方法利用 MaBoSS，这是一种随机模拟工具，它实现了布尔动力学蒙特卡罗算法来解决 BN 中的时间解释问题。这种概率估计方法允许通过随机模拟有效地探测 BN 动力学，克服了详尽的 STG 分析的计算限制。我们的框架还提供强大的 BN 集成可视化和分类功能。通过多个用例，我们展示了 AstroLogics 如何促进对 BN 集成中模型多样性的全面分析和关键监管结构的发现。 可用性和实施​​ AstroLogics 包以及教程和数据集可从 https://github.com/sysbio-curie/AstroLogics 获取
