pyGENIE：用于 AACR 项目 GENIE 的编程访问和突变分析的 Python 库

  • 日期：2026-11-20
  • 作者：未提供
  • 文章类型：期刊文章
  • 研究问题：截至目前，AACR Project GENIE 自 2015 年启动以来已完成 19 次数据发布。

核心发现：

  1. 最新发布的数据包含来自近 250,000 名患者的超过 268,000 个样本，截至 2026 年 2 月，超过 1730 篇科学期刊文章引用了 Project GENIE 数据。
  2. 尽管规模庞大且具有科学影响力，但 GENIE 数据的程序化分析通常仍然需要研究人员直接处理复杂的平面文件并开发自定义数据集成工作流程。
  3. 在这里，我们介绍了 pyGENIE，这是一个 Python 包，它提供了一个统一的 API，用于访问 GENIE 平面文件、执行临床和基因组查询、计算肿瘤突变负担，以及与包括 SigProfiler 和 SigMA 在内的领先突变特征分析工具集成。

摘要：截至目前，AACR Project GENIE 自 2015 年启动以来已完成 19 次数据发布。最新发布的数据包括来自近 250,000 名患者的超过 268,000 个样本，截至 2026 年 2 月，超过 1730 篇科学期刊文章引用了 Project GENIE 数据。尽管规模庞大且具有科学影响力，但 GENIE 数据的程序化分析通常仍然需要研究人员直接处理复杂的平面文件并开发自定义数据集成工作流程。结果：在这里，我们介绍了 pyGENIE，这是一个 Python 包，它提供了一个统一的 API，用于访问 GENIE 平面文件、执行临床和基因组查询、计算肿瘤突变负担，以及与包括 SigProfiler 和 SigMA 在内的领先突变特征分析工具集成。遵循数据即服务范例，pyGENIE 将所有结果作为本机 pandas DataFrame 返回，从而实现与机器学习和可视化库的无缝集成。应用于肺腺癌 (LUAD) 案例研究时，pyGENIE 重现了已知的突变频率、共突变模式和突变特征，同时将所需的代码库减少了大约一个数量级。可用性：pyGENIE 可根据 MIT 许可证在 https://github.com/gersteinlab/pyGENIE 上免费获取，存档于 https://doi.org/10.5281/zenodo.21981945，并且可以使用 pip install pygenie-sdk 从 PyPI 安装。补充信息：补充数据可在生物信息学在线获取。

RNAcomp2D：一种网络工具，用于执行多种方法并直观地比较 RNA 二级结构的预测

  • 日期：2026-11-20
  • 作者：未提供
  • 文章类型：期刊文章
  • 关键词：RNA二级结构, 比较, 深度学习, 预测方法, 可视化
  • 研究问题：核糖核酸 (RNA) 参与许多重要的生物过程。

核心发现：

  1. 特别是，非编码 RNA 是细胞过程的重要调节因子，在基因表达中发挥着重要作用。
  2. RNA 二级结构是推断其特定功能以及了解它们如何与其他分子相互作用的关键。
  3. 在过去的十年中，人们开发了许多计算模型来预测二级结构，并取得了越来越高的成功率。

摘要：核糖核酸 (RNA) 参与许多重要的生物过程。特别是，非编码 RNA 是细胞过程的重要调节因子，在基因表达中发挥着重要作用。 RNA 二级结构是推断其特定功能以及了解它们如何与其他分子相互作用的关键。在过去的十年中，人们开发了许多计算模型来预测二级结构，并取得了越来越高的成功率。然而，每种新方法都有自己的输入输出接口、编程语言、计算要求，有时还需要运行模型的专用服务器或存储库中的源代码。因此，如今很难从多种方法中获得预测并立即进行比较。迫切需要一个统一的界面，它允许同时访问多种方法，可视化和比较它们之间的预测，并且还需要一个可用的参考结构。结果：我们在此介绍 RNAcomp2D，这是一种基于网络的工具，允许用户输入 RNA 序列，或从 RNAcentral 中选择一个序列，并使用几种最先进的方法获得 RNA 二级结构的预测。经典的热力学方法和最新的深度学习模型都被打包在容器中，并可以在统一的网站上访问。所有预测以及参考结构（如果可用）都会同时显示在单个图形界面中。此外，随着新模型的不断开发，该工具被设计为可扩展的，允许在未来添加更多的预测方法。可用性：Web 服务器可从 https://sinc.unl.edu.ar/web-demo/rnacomp2d/ 获取。数据和源代码可在 https://github.com/sinc-lab/RNAcomp2D 获取。 补充信息：补充数据可在生物信息学在线获取。

ABAQS：评估基因组注释质量的综合评分方法

  • 日期：2026-11-20
  • 作者：未提供
  • 文章类型：期刊文章
  • 研究问题：随着基因组资源的不断扩大，估计基因组注释（例如基因和蛋白质模型）的准确性和完整性对​​于确保下游分析和应用的质量变得至关重要。

核心发现：

  1. 在比较基因组分析中，选择具有可比组装和注释质量的基因组变得至关重要。
  2. 如果不仔细审查，注释质量的不一致可能会破坏下游研究。
  3. 我们开发了基于准确性的注释质量评分（ABAQS），这是一种全面评估基因组注释质量的新方法。

摘要：随着基因组资源的不断扩大，估计基因组注释（例如基因和蛋白质模型）的准确性和完整性对​​于确保下游分析和应用的质量变得至关重要。在比较基因组分析中，选择具有可比组装和注释质量的基因组变得至关重要。如果不仔细审查，注释质量的不一致可能会破坏下游研究。结果：我们开发了基于准确性的注释质量评分（ABAQS），这是一种全面评估基因组注释质量的新方法。 ABAQS 评估多种因素，包括基因组完整性、基因模型有效性和蛋白质图谱准确性，提供比 BUSCO 和 PSAURON 等指标更完整的注释质量图。我们将 ABAQS 应用于 1700 多个真核真菌和藻类基因组，并展示了其在评估基因组注释质量方面的稳健性和有效性，使其成为研究人员处理基因组数据的宝贵工具。可用性：ABAQS 软件可从 https://github.com/mycocosm-lbl/abaqs 获取。它需要 Java SDK 版本 > =21 和 Maven。我们还在 DockerHub 上提供了 Docker 镜像。补充信息：补充数据可在生物信息学在线获取。
