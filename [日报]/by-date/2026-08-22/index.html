ToxiVerse：化学生物信息分析平台、毒性数据共享系统及可定制的预测建模工具

  • 日期：2026-08-22
  • 作者：未提供
  • 文章类型：未提供
  • 研究问题：化学毒性的评估对于药物研发与环境安全而言至关重要。

核心发现：

  1. 计算模型已成为替代动物实验的一种有前景的方法，如今在高效评估新化学物质方面发挥着重要作用。
  2. 为满足计算毒理学领域对用户友好型机器学习工具的迫切需求，我们开发了ToxiVerse这一公共在线平台。
  3. ToxiVerse为缺乏编程能力的研究人员提供了自动化的化学生物特性分析功能、精心整理的毒性数据集，以及专为他们设计的预测建模工具。

摘要：化学毒性评估在药物研发与环境安全领域具有重要意义。计算模型作为一种替代动物实验的有效手段，现已在新型化学品的安全性评价中发挥着关键作用。为满足计算毒理学领域对用户友好型机器学习工具的迫切需求，我们开发了ToxiVerse这一公共在线平台。 ToxiVerse为缺乏编程经验的研究人员提供了自动化化学生物特性分析功能、经过精心整理的毒性数据集以及预测建模工具。该平台由三个集成模块组成： 1. 生物特性分析模块：通过结合PubChem数据库中的化学-生物活性数据与基于机器学习的 数据填补技术，生成相应的化学描述符； 2. 数据库模块：存储了约50,000种涵盖多种毒性评价指标的化学物质信息； 3. 化学信息学模块：支持数据上传、化学物质信息整理，并能自动生成用于毒性预测的定量结构-活性关系模型。 使用方式 该工具可通过官网www.toxiverse.com访问，其源代码亦可在https://github.com/zhu-research-group/toxiverse获取。

链接：https://academic.oup.com/bioinformatics/advance-article/doi/10.1093/bioinformatics/btag617/8768655?rss=1

利用大型语言模型搜索可被药物作用的基因组区域

  • 日期：2026-08-22
  • 作者：未提供
  • 文章类型：未提供
  • 研究问题：可被药物作用的基因组包括那些已知或被认为能与药物发生相互作用的基因。

核心发现：

  1. 药物-基因相互作用数据库（DGIdb）为探索这些相互作用及其具体背景提供了综合性的资源支持，能够服务于多种研究和临床应用领域。
  2. 目前，DGIdb是通过结构化的网页界面或API调用进行访问的，因此用户需要将自然语言问题转换为该数据库所支持的查询语句格式。
  3. 为了使人们能够通过自然语言来使用 DGIdb，我们开发了 DGIdb 模型上下文协议（MCP）服务器。该服务器使得大型语言模型能够通过 DGIdb API 获取最新的信息。

摘要：可被药物作用的基因组包括那些已知或被认为能与药物发生相互作用的基因。药物-基因相互作用数据库（DGIdb）为探索这些相互作用及其背景信息提供了集成资源，支持多种研究和临床应用。目前，人们主要通过结构化的网页界面或API调用来访问该数据库，这意味着用户需要将自然语言问题转化为数据库特定的查询语句才能获取所需数据。为了实现通过自然语言直接使用DGIdb，我们开发了DGIdb模型上下文协议（MCP）服务器，使得大型语言模型能够通过DGIdb API获取最新信息。实验结果表明，MCP服务器显著提升了大型语言模型回答那些需要从结构化外部资源中提取准确、最新生物医学知识的问题时的能力。 关于DGIdb MCP服务器的更多信息及使用说明，请访问：https://github.com/griffithlab/dgidb-mcp-server

链接：https://academic.oup.com/bioinformatics/advance-article/doi/10.1093/bioinformatics/btag632/8768654?rss=1
