驯服参考基因组丛林：refget 序列收集标准

  • 日期：2026-07-31
  • 作者：未提供
  • 文章类型：期刊文章
  • 研究问题：参考基因组是基因组学的基础，但由于命名不一致、未记录的差异以及缺乏正式的比较机制，参考基因组普遍存在模糊性和不兼容性。

核心发现：

  1. 为了解决这个问题，我们引入了 GA4GH refget 序列集合 (seqcol) 标准。
  2. Refget seqcol 是一个用于明确表示、检索和比较序列集合（例如参考基因组和转录组）的框架。
  3. seqcol 标准包含四个组件：结构化数据模式、生成基于内容的全局唯一标识符的规范编码算法、检索 API 和比较协议。

摘要：参考基因组是基因组学的基础，但由于命名不一致、未记录的差异以及缺乏正式的比较机制，因此存在广泛的模糊性和不兼容性。结果为了解决这个问题，我们引入了 GA4GH refget 序列集合 (seqcol) 标准。 Refget seqcol 是一个用于明确表示、检索和比较序列集合（例如参考基因组和转录组）的框架。 seqcol 标准包含四个组件：结构化数据模式、生成基于内容的全局唯一标识符的规范编码算法、检索 API 和比较协议。该标准甚至可以跨分散或私有系统实现序列集合的精确识别，并允许超越精确身份的兼容性评估，例如顺序宽松的匹配或共享坐标系。我们将 refget seqcol 标准应用于来自主要提供商的 60 个人类和 36 个小鼠参考基因组。使用基于摘要的比较，我们量化了属性之间的相似性水平，包括序列名称、长度、坐标系和实际序列内容。我们的分析揭示了序列或坐标系的一些一致子集，以及不同名称下的参考文献和重复参考文献之间的实质性不兼容性。这项工作为参考基因组兼容性危机提供了可扩展、可重复的解决方案，从而提高了基因组分析的透明度、重用性和集成性。 Refget seqcol 增强了工具和数据集之间的互操作性，使基因组研究更加稳健和可重复。 可用性和实施​​ 为了支持 refget seqcol 的采用，我们提供了一个实施完整标准的 Python 包、一个 Web API 和一个比较接口，允许用户根据精选数据库评估本地引用。正式规范托管在 https://ga4gh.github.io/refget/ ，参考实现可以在 https://github.com/refgenie/refget 找到

链接：https://academic.oup.com/bioinformatics/advance-article/doi/10.1093/bioinformatics/btag554/8748372?rss=1
